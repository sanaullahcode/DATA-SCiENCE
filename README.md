# APTURA TECH SOLUTIONS — Data Science Internship

## Week 01 | Task 01: Exploratory Data Analysis (EDA)

### Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on a public dataset containing at least 1,000 records. The objective is to clean and analyze real-world data and extract meaningful insights using statistical analysis and data visualization techniques.

The project also identifies the three most influential features affecting the target variable and explores how the data processing workflow can be redesigned to handle datasets containing up to 10 million records.

### Objectives

* Perform data cleaning and preprocessing.
* Identify and handle missing values.
* Analyze individual features and their distributions.
* Create meaningful data visualizations.
* Perform correlation analysis.
* Identify the three most influential features affecting the target variable.
* Evaluate scalability challenges when processing 10 million records.

### Tasks Performed

**1. Data Cleaning**

* Inspect the dataset structure and data types.
* Identify duplicate records and inconsistencies.
* Prepare the dataset for analysis.

**2. Missing Value Handling**

* Identify missing values in relevant columns.
* Apply appropriate strategies to handle missing data.

**3. Feature Analysis**

* Examine numerical and categorical features.
* Analyze feature distributions and relationships.
* Identify important patterns and trends.

**4. Data Visualization**

* Use charts and plots to understand the dataset.
* Visualize feature distributions and relationships.
* Present findings in a clear and interpretable format.

**5. Correlation Analysis**

* Examine relationships between numerical variables.
* Use statistical evidence and visualizations to support findings.
* Identify the three most influential features associated with the target variable.

**6. Large-Scale Data Processing**

* Discuss challenges associated with scaling from 1,000 rows to 10 million rows.
* Explore memory-efficient processing techniques.
* Consider chunk-based processing and scalable data analysis workflows.

### Research Questions

**Question 01: Feature Importance**

Which three features have the strongest influence or association with the target variable?

The analysis uses statistical evidence and visualizations to support the selection of the three most important features.

**Question 02: Scalability**

What challenges would arise if the dataset increased from 1,000 rows to 10 million rows?

The discussion covers memory limitations, processing time, computational resources and workflow optimization strategies.
